# Tasks for Today Management System – SA2

A CodeIgniter 4 task management system with authentication, task creation, editing, and soft-delete archiving.

## Developer

John Vincent Beasca

## Technologies Used

- PHP
- CodeIgniter 4
- MySQL
- HTML
- CSS
- XAMPP
- Visual Studio Code

## Features

### Public Features

- Welcome page
- Display of today’s tasks
- Complete task list
- User profile page
- About page
- Login page

### Authenticated Features

- Secure login using hashed passwords
- Session-based authentication
- Logout
- Add new tasks
- Edit existing tasks
- Archive tasks
- Validation for task forms
- CSRF protection
- Protected task-management routes
